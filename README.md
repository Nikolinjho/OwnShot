# OwnShot

OwnShot – приложение для скриншотов и записи экрана на macOS. Из меню в строке состояния можно захватить область, окно или длинную страницу, записать видео или GIF. Снимки можно открыть в редакторе, добавить заметки и скрыть фрагменты перед экспортом. Записи можно открыть в видеоредакторе и обрезать.

## Сборка из исходников

Нужны macOS, Xcode и Python 3. Один раз создай локальный сертификат, затем собери и запусти приложение.

```sh
./scripts/create-signing-cert.sh
./scripts/build-ownshot.sh --run
```

Приложение установится в `~/Applications/OwnShot.app`. Чтобы собрать его без установки, запусти `./scripts/build-ownshot.sh`. [Настройка локальной подписи](docs/local-signing.md).

Открой меню OwnShot и выбери действие. При первом захвате разреши запись экрана в Системных настройках macOS. Чтобы изменить сочетания клавиш, открой вкладку Shortcuts в настройках OwnShot.

## Тесты
