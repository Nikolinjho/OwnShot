# Команды Focus для записи

OwnShot вызывает публичный `/usr/bin/shortcuts`, без private API и записи в системную базу Focus. В настройках записи кнопка Set Up открывает три подписанные команды. Их нужно добавить в macOS «Команды» и вручную разрешить вывод текущего Focus при первом запросе системы.

Status возвращает имя текущего Focus, пустой результат означает выключенный Focus. On включает только Do Not Disturb до текущего времени плюс180с. Служба продлевает срок каждые60с, завершение записи вызывает Off. Если процесс OwnShot аварийно завершится, системный конечный срок продолжает действовать. Эти180с должны совпадать с производственным сроком RecordingFocusSession.

Квитанция On содержит идентификатор намеренной цели DND и её имя. Имя нельзя получать через Get Current Focus после включения: пользователь мог выбрать другой режим во время ожидания команды. Служба получает право на очистку только при совпадении статуса с именем намеренной цели. Уже включённый Focus оставляется без изменений.

Поставленные ресурсы собраны для английского имени `Do Not Disturb`. Для другого языка нужно пересобрать On с нативным именем целевого DND через `--dnd-name`, подписать и заменить команду. Например:

```bash
python3 scripts/make-focus-shortcuts.py --output /tmp/ownshot-focus --dnd-name 'Не беспокоить'
shortcuts sign --mode anyone --input '/tmp/ownshot-focus/OwnShot Focus On.unsigned.shortcut' --output 'Snapzy/Resources/FocusShortcuts/OwnShot Focus On.shortcut'
```

Текстовый публичный статус не различает два режима с одинаковым именем и ручное выключение с повторным включением того же DND между проверками. Для таких случаев нельзя обещать безусловное владение режимом. Периодические проверки и короткий системный срок ограничивают работу службы.

Схема нативного Adjust Date и Time взята из [публичного экспорта команды](https://github.com/findlaywebb/shortcut-lib/blob/main/samples/decoded/start_pomodoro.xml). Сам интерфейс CLI описан в [документации Apple](https://support.apple.com/guide/shortcuts-mac/run-shortcuts-from-the-command-line-apd455c82f02/mac). Живые результаты приёмки сохраняются в `evidence/fixes-036`.
